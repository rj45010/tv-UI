# Devices

One folder per TV model, named `<brand>-<model>-<android version>`, with:

- `README.md`: model, OS build, quirks the launcher had to work around, and anything that broke.
- `debloat.txt`: packages to disable, one per line, with a comment on any that are risky.

Add yours with a pull request. Only list packages you disabled on your own TV and lived with for a few days.
